**Interview 04 · Resident, Block F 4th Floor · (code name: Resident-F4)**

**Week:** 2 · **Asker:** AK · **Logger:** GU · **Consent:** yes; notes only, no recording  
**Real or practice:** real

**Context:** 2nd-year student living on the 4th floor of Block F, does laundry about once a week, usually in the evening. We wanted to understand whether residents would be willing to manually update a machine's status when starting or finishing a load.

**Quotes** (Georgian; English beside it; ★ = surprise)

- "თუ უბრალოდ QR-ის დასკანერება იქნება და ორ წამს წაიღებს, ალბათ გავაკეთებდი." / "If it's just scanning a QR code and takes two seconds, I'd probably do it."
- "მაგრამ თუ ყოველ ჯერზე რაღაცის შევსება მომიწევს, რამდენიმე დღის მერე აღარავინ გააკეთებს." / "But if I have to fill something in every time, after a few days nobody will do it."
- "ყველაზე დიდი პრობლემა ისაა, რომ თუ ერთმა არ მონიშნა სწორად, მერე აღარ იცი ინფორმაციას ენდო თუ არა." / "The biggest problem is that if one person doesn't update it properly, then you don't know whether you can trust the information." ★
- "დაწყებისას დასკანერება უფრო რეალურია, მაგრამ დამთავრებისას შეიძლება დამავიწყდეს." / "Scanning when starting is more realistic, but I might forget to do it when it finishes."
- "თუ სისტემამ თვითონ იცის რამდენ ხანს გრძელდება რეცხვა, მაშინ მხოლოდ დაწყების მონიშვნა ჯობია." / "If the system already knows how long the wash takes, then it would be better to mark only when it starts."

**Workaround:** Currently checks machine availability by going downstairs. Sometimes asks friends or sends a message in the dorm chat before taking laundry down.

**Cost:** Because the resident lives on the 4th floor, checking manually means unnecessary trips downstairs, especially when all machines are already occupied.

**Frequency:** Says full machines are common in the evenings and on weekends.

**Prediction check:** Partially confirmed. The resident would be willing to interact with a status marker, but only if it is extremely quick and requires almost no effort.

**Surprise ★:** The main concern was not scanning itself, but reliability. They said a manual system becomes useless quickly if residents forget to update the machine status.

**Commitment:** Said they would be willing to test a QR-based version if it only required one quick scan when starting a wash.

**Next:** In Interview 05, investigate whether residents would trust a system where they only scan once when starting a load and the remaining time is calculated automatically.
